  Only write floorplan content to DEF file. (bool, optional)

-no_logical_stdcell
  Not to write logical stdcell (source not dist and class core) to DEF file. (bool, optional)

-no_routing
  Not write regular nets to DEF file. (bool, optional)

-no_scanchain
  Not write scan chains to DEF file. (bool, optional)

-no_special_net
  Not to write special net to DEF file.

<file_name>
  Specifies the DEF file name to write. (string, required)
