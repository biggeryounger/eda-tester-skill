# 243.COMMAND
## Description
**insert_clock_tree_source_group_roots** - Create a multi-tree 'source group' under the specified source driving pin. A source group consists of multiple, logically equivalent clock trees that collectively drive a set of clock tree sinks.
        The command performs three main actions:
          1. Inserts the intended clock tree root instances into the netlist. Their input pins connect to the root pin, while the fanout originally driven by the root pin is rerouted to the output of a single root instance.
          2. Defines clock trees at the outputs of each newly inserted root instance.
          3. Creates a clock source group that unifies these clock trees.
        The assignment of individual sinks to specific source group roots will be done during CTS.
