# 输入规则

## 命令资料

接受命令说明、帮助文本、自然语言需求或已有测试用例设计表。目标工具必须明确；不询问或要求工具版本，按命令资料校验。TXT 输入先交给 [命令解析器](../scripts/parse_command_spec.py)，保留 `schema_version`、命令、选项、类型、枚举、必选性、约束及来源；未说明的语义记录 `SPEC-GAP`，不得猜测。

帮助文本可由 [帮助采集器](../scripts/dump_tool_help.tcl) 的 `eda_dump_all_help` 获取。采集失败不作为命令不支持的证据。

## 工艺与设计

工艺固定为 `SMIC180`，不询问、不要求用户选择或确认工艺。唯一来源为 [输入件管理表](../assets/输入件管理表.json) 的 `smic180` 对象：`tech_dir`、`lef_files`、`lib_files` 必须完整、可移植；不得回退其他工艺。

运行输入按 [通用模板](../assets/templates/tool_cmd/common/design.tcl) 与目标工具模板组织。用户设计的顶层、网表、SDC、可选 DEF 必须由已提供的输入或明确的测试构造确定，不得把示例设计当作用户设计。缺失、歧义或冲突时停止脚本生成并进入 `WAIT-PLAN-FIX`，列出问题。

已有设计表跳过策略选择与重新设计；不重新执行场景设计或策略选择，不得擅自改写已给出的用例设计。验证通过后按表逐行生成。
